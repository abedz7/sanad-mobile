# sanad-mobile

End-user mobile app for **Sanad**, a support-ticket / helpdesk system. Expo · React Native · TypeScript.

Built against the contract in [`docs/API.md`](docs/API.md) (a verbatim copy of
`sanad-server/docs/API.md`; the server owns it). Requires a running `sanad-server`.

> Work in progress — setup, demo account and screenshots are added as each phase ships.
